Court Session

The court site now shows a "verify you are human" check that the server can't clear on its own. Paste a fresh session so scrapes can read case dockets. (Property addresses work without this; dockets and scores do not.)

  1. Open the court search page and complete the "Verify you are human" check so the real search page loads.
  2. Press F12 → click the Application tab → in the left sidebar under Cookies click https://courtsapp.montcopa.org.
  3. Find the row named ASP.NET_SessionId, double-click its Value cell, and copy it (Ctrl+C). You can also paste the full Cookie request header if the court created more than one cookie.
  4. Paste it below and click Save Session, then start a scrape right away (sessions go stale after ~20 min idle).
